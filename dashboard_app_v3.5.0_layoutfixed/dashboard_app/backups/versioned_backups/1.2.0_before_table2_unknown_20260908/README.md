# DHA Data Dashboard v1.1.0

## Run on Windows
1. Open PowerShell in this folder.
2. Run `python -m pip install -r requirements.txt`.
3. Run `python run_app.py`, or double-click `run_dashboard.bat`.
4. Use **Browse** or retain the default `C:\Users\Sankar.Sasmal\OneDrive - Shell\Desktop\PuthonDashboard\DHA` path.
5. Click **Process files**.

The browser cannot preselect a local directory for security reasons. The Browse button calls the local Python backend's native Windows folder picker. If the native picker is unavailable, enter the path manually.
